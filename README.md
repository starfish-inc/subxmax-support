<h3>アプリについて</h3>
<p>Sub-X Max は、Apple HealthKit のランニングデータを活用し、マラソンの目標達成をサポートするアプリです。</p>
<ul>
  <li>距離・ペース・VO2Max・体重の可視化</li>
  <li>インターバルトレーニングの自動解析</li>
  <li>AIコーチによる講評と相談</li>
  <li>走行動画によるフォーム解析（端末内で解析）</li>
  <li>体重・睡眠などの「からだの記録」の表示</li>
  <li>目標レース管理とアーカイブ</li>
</ul>

<h2>プライバシーポリシー</h2>

<h3>1. HealthKitデータの取り扱い</h3>
<p>本アプリは、Apple HealthKitから以下のデータを<strong>読み取り専用</strong>で取得します：</p>
<ul>
  <li>ランニングワークアウト（距離・時間・ペース・心拍数等）</li>
  <li>VO2Max</li>
  <li>体重・体脂肪率・身長</li>
  <li>安静時心拍・心拍変動（HRV）</li>
  <li>睡眠・歩数</li>
  <li>血圧（収縮期・拡張期。血圧計などからヘルスケアに記録がある場合）</li>
</ul>
<p>取得したデータは<strong>お使いの端末内にのみ</strong>保存され、AI機能を利用しない限り外部送信されることはありません。これらの表示は記録を見やすく並べるためのもので、診断や医学的な判定は行いません。</p>
<p>なお、アプリ内で GPS 記録したランは、ワークアウト（ルート・距離・消費エネルギー）としてヘルスケアに書き込みます。</p>

<h3>1-2. フォーム解析の動画の取り扱い</h3>
<ul>
  <li>フォーム解析のために撮影・選択した走行動画は、<strong>端末内で解析</strong>し、アプリ内（端末内）に保存します。動画が外部へ送信されることはありません</li>
  <li>保存した動画は、アプリ内でいつでも削除できます（動画だけ削除して数値を残すこともできます）</li>
  <li>動画は iCloud バックアップの対象から外しています</li>
</ul>

<h3>2. 第三者AIサービス（Google Gemini API）へのデータ送信</h3>
<p>本アプリには、Google LLCが提供するGoogle Gemini APIを使用する<strong>AI機能</strong>が含まれます。これらの機能は<strong>デフォルトでは無効</strong>になっており、ユーザーがアプリ設定画面の「AI機能を有効にする」トグルをONにし、同意ダイアログで明示的に同意した場合のみ利用可能になります。</p>

<p><strong>【送信先】</strong><br>
Google LLC（Google Gemini API）<br>
エンドポイント: https://generativelanguage.googleapis.com</p>

<p><strong>【中継サーバーについて】</strong><br>
AI機能のデータは、当アプリの中継サーバー（Cloudflare, Inc. のサービス上で運用）を経由して Google LLC へ送信されます。中継サーバーは送信内容（走行データ・入力内容・AIの応答）を保存しません。不正利用を防ぎ利用回数を集計するため、端末ごとの匿名の識別子（Apple の App Attest 機能による。氏名・メールアドレス等は含みません）と利用回数のみを記録します。</p>

<p><strong>【AI機能①：AIコーチ機能】</strong><br>
送信されるデータ：</p>
<ul>
  <li>走行距離、ペース、走行回数</li>
  <li>インターバルトレーニング記録</li>
  <li>VO2Max、体重（平均値）</li>
  <li>心拍数（ランごとの平均）</li>
  <li>目標レース名、目標タイム</li>
  <li>練習計画</li>
  <li>過去のコーチングコメント</li>
  <li>設定したユーザー名、相談時に表示していた画面の要約</li>
  <li>週・月・年ごとの集計値（距離・時間・ペース・心拍・インターバル・推定VDOT・VO2Max・負荷の目安）</li>
  <li>「からだの記録も講評に含める」をユーザーがオンにした場合のみ：体重・体脂肪率・安静時心拍・心拍変動（HRV）・睡眠時間の、期間ごとの平均（<strong>既定ではオフ</strong>。血圧は送信しません）</li>
</ul>
<p>利用目的：コーチングコメント・講評の生成</p>

<p><strong>【フォーム解析の AI 所見】</strong><br>
送信されるデータ：</p>
<ul>
  <li>動画から端末内で算出したフォーム指標の数値（ケイデンス・接地時間・角度など）</li>
  <li>目標タイム・走りの強度の区分</li>
</ul>
<p>動画・写真そのものは送信されません。利用目的：フォームの所見を文章にまとめること</p>

<p><strong>【AI機能②：ニュース取得機能】</strong><br>
送信されるデータ：</p>
<ul>
  <li>ユーザーが登録したレース名</li>
  <li>ユーザーが登録したシューズ名</li>
</ul>
<p>利用目的：関連ニュース記事の検索・取得</p>

<p><strong>【AI機能③：レース情報自動取得機能】</strong><br>
送信されるデータ：</p>
<ul>
  <li>ユーザーが入力したレース名</li>
</ul>
<p>利用目的：大会公式URL・開催日・エントリー開始日の取得</p>

<h3>3. 同意と無効化</h3>
<ul>
  <li>初回のAI機能使用時に明示的な同意画面を表示します</li>
  <li>同意しない場合、AI機能は利用できません</li>
  <li>同意後も、アプリ設定画面の「AI機能を有効にする」トグルから<strong>いつでも無効化</strong>できます</li>
  <li>無効化中は、すべてのAI機能でデータ送信は一切行われません</li>
</ul>
